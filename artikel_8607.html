Tanggal: 2026-11-03

We have considered doing a "physical notebook" and may do it once we get the number of locations that require login credentials reduced. There could be advantages to storing login credentials offline. There might be advantages to having a notebook if cognitive decline becomes an issue. A possible drawback is, human nature would likely creep in and folks would end up with less secure passwords.
I have not read the book yet.

Instead of a physical notebook so far what I have been doing is to use an encrypted USB flash drive where I have a web sites and clues for what the actual password is. That means that I only need to remember the password for the USB drive.
