Pydantic AI v2.70.0 (released 17 November 2026) shipped with two high-severity security advisories in pydantic-ai-harness (GHSA-5m5q-5qj4-gx9h and GHSA-m4cr-m4qc-9hh3) that expose a dangerous architectural blind spot in how most engineering teams wire async agent guardrails and tool output sanitizers.

Both vulnerabilities share the same root weakness: CWE-1333 (Inefficient Regular Expression Complexity) executing synchronously on the Python asyncio event loop before or independent of payload size limits.

Almost every production Python agent service uses asyncio (via FastAPI, Starlette, or an async worker pool) so a single worker process can multiplex dozens of concurrent agent runs waiting on network I/O (LLM streams, vector searches, MCP calls).
