GHSA-JPF8-86F3-WP38: CVE-2026-48752: Arbitrary Host File Read and Write via Templates Symlink in Canonical LXD and Incus

Tanggal: 2026-11-06

Posted on Nov 6 • Originally published at cvereports.com

Vulnerability ID: GHSA-JPF8-86F3-WP38 CVSS Score: 9.9 Published: 2026-11-06

A symbolic link traversal vulnerability (CWE-59) in Canonical LXD and Linux Containers Incus allows an authenticated user with image import permissions to read and write arbitrary files on the host filesystem. During image archive unpacking, the daemon fails to reject top-level symbolic links for the instance templates directory. Subsequent requests to the instance template API endpoints follow this symbolic link outside the instance storage directory with root privileges, enabling complete host compromise.

Authenticated users capable of importing images into LXD or Incus can include a symbolic link at the templates path inside an image tarball. Interacting with the instance template management API causes the root daemon to traverse this symlink onto the host filesystem, granting arbitrary file read and write access as root.
