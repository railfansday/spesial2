Vibe coding increased my uptime to 99.96% or How to vibe code an app with actual users.

Tanggal: 2026-11-12

1/ Vibe coding increased my uptime to 99.96% or How to vibe code an app with actual users.

sounds backwards. the ai still makes mistakes but i did three things that catch errors before users do.

tests used to be a chore. i used to add just enough tests, after the fact, to get some of the upside without incurring the tediousness of testing everything and keeping tests updated.

with ai, test driven development is effortless and essential. tests limit the mistakes the agent can make and allows you to ship with confidence. every code change writes tests first across all "ranges" unit, api, integration, and browser.

3/ second, log everything and make sure your agents have access to the logs. if I was consulting on AI dev, this would be the first thing I would recommend. if every request, job and deploy leaves a log line, an agent can read the whole state of the app, debugging becomes instant, and decisions are informed by what actually happened, no guessing.

agents launch app instances and clients on demand, stage data and users, and exercise what was built.

5/ if UX is involved, record it. both phone sessions get recorded from the start, cropped to the screen, so i can watch what the agent saw before anything ships.

6/ after merging, back to the logs. evaluate the release, are things working as expected? did we let any bugs slip through?

7/ enjoy. development has never been so much fun
