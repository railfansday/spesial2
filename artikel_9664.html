Measuring Calls and Forms Before A/B Testing a Law Firm Site

Tanggal: 2026-11-04

If you build or maintain sites for criminal defense firms, someone will eventually ask you to "run an A/B test" on a charge page. Before you pick a tool, check whether the site can measure the thing the firm cares about. On most defense sites that is a phone call from a mobile visitor, and a surprising number of sites record it poorly or not at all.

Testing without reliable conversion data produces confident charts about nothing. This post covers the measurement groundwork that should be in place first, with notes on the constraints that make legal sites different from ecommerce.

Google Optimize was shut down on September 30, 2023, so many teams now pair GA4 with a separate testing tool or run server-side experiments. Whatever you choose, the conversion events have to exist in analytics first.

Fire the form event only after the server confirms the submission. Firing on button click counts failed validations and double taps. Add a data attribute to each phone link so you can tell header taps from in-content taps, which matters when the test changes where the number appears.

Google Analytics policies prohibit sending personally identifiable information, and a defense intake form collects some of the most sensitive data a website can hold: names, phone numbers, charges, arrest dates. None of it should reach analytics, a heat map tool or a session recorder.

Check a few things before any test goes live. Form fields should be excluded or masked in any recording tool. URLs should not carry form values as query strings after submission. Event parameters should describe the form, never its contents. If the firm uses a third-party form service, confirm where submissions are stored and who can see them.

A phone_tap event shows intent. It does not prove a call connected. Call tracking with dynamic number insertion can close that gap by showing a different number per source and logging calls on the provider's side. If you use it, keep the firm's main number consistent in the footer, schema markup and Google Business Profile so local search signals stay clean.

The richest data lives in intake. A short field asking how the caller found the firm, plus a weekly export, lets you compare test variants on signed cases rather than raw contacts. For the form side of that work, designing an intake form a frightened caller will finish covers how many fields to ask for and how to word labels for a scared person typing on a phone.

Most defense charge pages see modest traffic and few conversions. Run the numbers before you promise a result. If a page produces twenty calls a month, a split test chasing a ten percent lift will take far longer than anyone will wait.

With small numbers, test large changes to the first mobile screen, run variants for fixed periods and keep a change log in the repo. Before and after comparisons are weaker evidence than a true split, but they are often the only realistic option, and they are fine if you say so in the report.

Each variant is attorney advertising. If a test changes headlines, claims or disclaimers, the firm's lawyers need to approve it, and state bar advertising rules apply to every version a visitor might see. Build the approval step into your deployment process so a variant cannot ship by accident.
