I Built a Complete Arena Shooter in Vanilla JavaScript — No Engine, No Libraries, No Audio Files

Tanggal: 2026-11-19

Every sound in VOIDSTORM — the music, the laser shots, the boss roar — is synthesized live with the Web Audio API. There is not a single audio file in the repository. The whole game is vanilla JavaScript and Canvas 2D: no engine, no framework, no build step. You open index.html and it runs.

▶ Play it in your browser: https://kamalmosadegh.github.io/voidstorm/game/ Source: https://github.com/kamalmosadegh/voidstorm

VOIDSTORM is a neon arena survival shooter. You pilot a lone ship against escalating waves: five enemy types with distinct behaviours, a multi-phase boss on wave 10, and an endless mode after victory. Between waves you draft upgrades — damage, fire rate, shields, drones — so every run builds differently.

1. A fixed-timestep loop with a seeded RNG. The simulation advances in fixed steps and renders interpolate between them, so gameplay speed is identical on a 60 Hz laptop and a 144 Hz monitor. All randomness comes from a seeded generator, which means a run is reproducible — when a tester says "wave 7 is unfair", I can replay the exact run they played.

2. Synthesized audio instead of files. A tiny WebAudio synth stack generates everything: oscillators and noise buffers for shots and explosions, a procedural bassline and arpeggio for the soundtrack. The trade-off is real (you design sounds with envelopes, not samples), but the payoff is a game folder measured in kilobytes and zero asset licensing questions.

3. Object pooling everywhere. Bullets, particles and enemies are pooled and reused. On a busy wave the game holds hundreds of live entities; without pooling, garbage-collection pauses show up exactly when the action peaks. With pooling, the frame budget stays boring — which is what you want.

The upgrade draft started as a pure numbers game ("+10% damage") and tested flat. It only became fun when upgrades changed behaviour — split shots, piercing rounds, an orbiting drone. Numbers scale a run; mechanics diversify it.

VOIDSTORM is one of six projects I shipped in November 2026 — alongside an algorithmic Bitcoin trading bot, a token-valuation model ranking 204 protocols, and a second open-world browser game, Solmar Bay. Everything is on my portfolio: https://kamalmosadegh.github.io
