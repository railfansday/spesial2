Zapier vs Make in 2026: 100 tasks against 1,000 credits, a 10x gap in the numbers and a 2.5x gap in the work

Tanggal: 2026-11-22

Both pricing pages now sell a unit rather than a plan. Zapier counts tasks, Make counts credits, and since 27 August Make has said so explicitly: "each action your scenario performs consumes a certain number of credits — most actions consume 1 credit."

That single sentence is the reason the two free tiers cannot be compared as printed. 100 against 1,000 looks like a tenfold difference. It is not, because the two vendors count different events. Here is each page as it was served on 22 November 2026, then the arithmetic that makes them comparable, then the parts neither page will tell you.

Two things jump out of that table before any maths. Zapier's price moves with the task tier, not with the plan name — the page ships a selector from 100 tasks to 2 million and quotes $19.99 and $69 as the anchors. Make's price moves with the plan, and the credit allowance is a separate slider (10,000 was the default the page loaded with).

And on Make, the price per 1,000 credits rises as you climb: $0.90 on Core, $1.60 on Pro, $2.90 on Teams.

That is not a mistake. The higher plans are notcheaper volume — they are features (custom variables, log search, priority execution, team roles) attached to the same credits. If you only need more runs, the slider is the lever; if you need a feature, you pay a higher unit price for all of your credits.

Zapier: "Every step in a Zap and every external connector call uses tasks — though rates may vary. AI model tier, code runtime, and connector type each affect how many tasks an action uses." Tasks are pooled across the account, with no separate budgets per product. A Zapier MCP tool call costs two tasks.

Make: every module action is one credit. The Router and the error-handler modules (Rollback, Break, Resume, Commit, Ignore) cost nothing. The Code app costs two credits per second of execution time.

So the same four-module automation — a trigger, a filter, a transform and a create — spends roughly four credits per run on Make, while Zapier's own wording puts the charge on the action rather than on each module. The number of tasks a given Zap spends is not one per module; the page says it varies with the connector and with AI or code use.

A tenfold gap in the printed numbers is a 2.5× gap in the work, and it narrows further the moment a run has two actions or an MCP call in it.
