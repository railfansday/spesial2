Best TTS MCP Servers for Claude Code, Cursor & Codex (2026)

Tanggal: 2026-11-27

If you want Claude Code, Cursor, or Codex to generate speech via Model Context Protocol (MCP), the best Text-to-Speech (TTS) MCP server depends on whether you need offline alerts, low-latency streaming, or emotion-tagged multi-speaker audio exports.

If you use a coding agent to turn release notes, tutorials, or podcast scripts into audio regularly, 100,000 English characters (~16,000–18,000 words, or ~1.5–2 hours of spoken audio) is a realistic monthly benchmark:

ElevenLabs provides an official hosted MCP endpoint (https://api.elevenlabs.io/v1/mcp) as well as the legacy local elevenlabs/elevenlabs-mcp server (uvx elevenlabs-mcp, now archived in favor of the hosted server).

Community MCP servers built on the open-weight Kokoro-82M model—such as mberg/kokoro-tts-mcp and giannisanni/kokoro-tts-mcp—let you synthesize speech entirely on your own machine.

If you just want Claude Code or Codex to speak a quick summary aloud when a long build or test suite finishes, lightweight playback-oriented MCP servers are simpler than full production suites.

Cartesia's official MCP server (cartesia-ai/cartesia-mcp) exposes Sonic models optimized for sub-second interactive voice applications.

FlowSpeech MCP (mcp-flowspeech-server@0.3.0) is purpose-built for emotion-tagged narration, multi-speaker dialogue, and long-form WAV generation inside Claude Code, Cursor, Codex, and Claude Desktop.

With most stateless TTS wrappers, yes—re-sending the same prompt starts a new billable synthesis request. mcp-flowspeech-server@0.3.0 avoids this by deriving a deterministic HMAC-SHA256 UUIDv8 request_id automatically when omitted, so retrying the same script after an MCP timeout or restart reuses the original server job instead of charging twice.

Among commercial APIs, pay close attention to billing units: UTF-8 byte-billed APIs charge 3× as much per character for CJK text (since each Chinese/Japanese character uses 3 UTF-8 bytes), whereas character-billed plans like Cartesia Pro ($5/mo for 100k credits) and FlowSpeech Basic ($19/mo or $13/mo annual for 200k character credits) avoid the 3× CJK penalty.
