One table builder for all HTML reports - column types in a short string in Uniface ProcScript

Tanggal: 2026-11-16

Stage 32 of the customer app from the series Building a customer app in Uniface 10 added six analysis services. Each has a report that collects the results of the other operations into one HTML file with five or six tables. In stage 31 every table had its own loop with getitem, escaping and $concat calls - about 15 lines per table.

Tested with Rocket Uniface 10.4.03 Community Edition (10.4.03.021) on Windows, October 2026. The app uses SQLite through the SLE driver (SQLite 3.50.2).

All operations return their result the same way: sql/data gives a Uniface list, one item per row, and each row is a list of columns. Money is in cents, quantities in thousandths (QTY_MILLI).

A table needs to know three things: the title, the header and which columns to show in which format. The columns are passed as a string of pairs - a letter for the kind and a digit for the column:

T2T3Q4M6 means: column 2 and 3 as text, column 4 as quantity, column 6 as money. One digit is enough because no row has more than nine columns.

pCols[vI:1] is ProcScript's substring: start position and length. The loop steps through the string two characters at a time. The header is passed ready as HTML, because it is a constant in each report.

The header text is escaped once when the service is generated, not at runtime.
