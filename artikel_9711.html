In practice, almost every blog post stops at copying the 2022 OpenAI paper's parameter table. Nobody shows repeated Web Worker timings across operating systems, nobody tests Firefox vs WebKit vs Chromium, and almost nobody publishes the verbatim transcripts where small models quietly enter repetition loops.

On desktop Chrome, base.en (fp32) was roughly twice as fast AND more accurate than tiny.en (int8). Quantized int8 still cuts download size by ~73% (39 MB vs 144.5 MB), making it the right default for mobile browsers — while desktop browsers should default to fp32 once cached.

On ted_60s, which ends abruptly mid-sentence at 60.0s, whisper-small.en (int8) matched 189/189 spoken words verbatim (0.0% pre-cutoff WER) — then hallucinated six trailing repetitions at the hard cut-off (33.9% raw WER). Meanwhile faster-whisper-large-v3-turbo handled the exact same hard cut-off cleanly with zero trailing loops.
