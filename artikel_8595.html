That account is also the admin account mainly for convenience. Is it a best practice? No, but we're careful and I trust our Mac OS has protections in place that help keep our computer safe.
Using an admin account only when you are doing admin tasks is one of those protections. It is not just a security issue, but also protects against inadvertent changes that may break something.

It is not hard to convert to using a non-admin account— add another account, grant it admin privileges, test that a login to it is working by logging in to it, check that it shows up in the user list as an admin account, and use the new account to downgrade the current account to a non-admin account. The last step ensures that the new account has admin privileges, because that step would fail without it.
Even on the Mac, I setup a separate account for admin. This was definitely a thing I do in windows. Even though you need to approve elevated access, there is still a chance that some malware will somehow run as admin. By using a different account, you have to login using the other account.
