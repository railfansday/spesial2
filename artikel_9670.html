Day 3 never came. My son and I stopped racing and built a game engine.

Tanggal: 2026-11-04

In March, my son and I made a bet. 80 days. Build real software. Sell it. Father vs son, shipping every day.

We'd been racing each other. Breadth against depth. Me knocking on more doors, him polishing one thing until it shone.

Then we noticed something. We have different skills, and we think in different ways. What one of us lacks, the other brings.

And we'd both been making games and game engines for years. Separately.

So we stopped racing and started building together. Day 2 said we had to work smarter. This was it. Synergy turned out to be real.

Myth Engine is a game engine for 2D and 3D games. The games you make can run on the web, on desktop and on mobile. It's built with JavaScript and Babylon.js, and it uses ECS (entity component system), which makes putting a game together feel intuitive and helps games run fast.

You make games in the editor on Windows, with Visual Logic blocks, JavaScript, or both. The editor draws your level with the game's own runtime, so you see it as it will look in the game.

We didn't just build the engine. We made games with it.

2D and 3D games, shooters, puzzles, platformers, worlds made of blocks and science labs, all made in Myth Engine.

Every object is built from components that you add and tune. The same Object Editor builds 2D and 3D objects.

Game rules are Visual Logic blocks you connect: when something happens, such as a button press, do something. Build a behavior once and attach it to as many objects as you like.

Pause the game right before any block runs, step through it, and watch each object's values change.

JavaScript works instead of blocks or alongside them, with suggestions for your project's own objects and sounds as you type. JavaScript libraries can be added from a catalog, and they're bundled into your game.

Ready-made looks, from old film and Game Boy to thermal camera and comic-book print. Up to four can be combined.

Build new looks from connected blocks, or write them as code.

Particle effects in 2D and 3D, starting from presets such as fire, rain and confetti.

Generated worlds with hills, caves, ores and trees, and a map preview before you play. Block worlds can be built by hand too.

There's more in the full tour on itch.io: What Myth Engine can do.

The free version has no time limit. Exporting finished games needs the full version, which is a one-time purchase with no royalties.

Call this Day 3. It just took a little longer than a day.
