استفاده ایجنت‌های هوش مصنوعی از ایکس (توییتر) بدون نیاز به API و مرورگر با ابزار متن‌باز x-use

Tanggal: 2026-11-27

وقتی می‌خواهید ایجنت‌های کدنویسی و اتوماسیون (مثل Antigravity، Claude Code یا Cursor) را به پلتفرم‌هایی مثل X متصل کنید، بیشتر آموزش‌ها سراغ Puppeteer یا Playwright می‌روند.

اما در محیط واقعی و پایپ‌لاین‌های خودکار، این روش چند مشکل جدی ایجاد می‌کند:

از طرف دیگر، دسترسی نوشتن در API رسمی X هم برای بسیاری از پروژه‌های شخصی و ایجنت‌های سبک، محدودیت‌ها و هزینه‌های سنگینی دارد.

برای اینکه اجرای دستورات ایجنت سریع، سبک و قطعی باشد، ابزار x-use (agent-x-use) را ساختیم: یک CLI و SDK ماژولار با Node.js که مستقیماً روی https و اندپوینت‌های GraphQL شبکه X کار می‌کند.

کدبیس پروژه به ماژول‌های کوچک و تک‌منظوره تقسیم شده است:

سورس‌کد کامل تحت لایسنس MIT در دسترس است: 🔗 https://github.com/dalroot/x-use
