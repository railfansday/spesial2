ChatGPT and Claude are not down as a whole, but both AI assistants have lost access to users’ Microsoft work data because of the ongoing Microsoft 365 outage. The problem lies in the Microsoft 365 connectors that let the assistants read Outlook email, calendars, Teams chats and SharePoint files. Since that data sits on Microsoft’s servers, the connectors stopped working once those servers failed on Thursday. OpenAI’s status page shows elevated errors for its Microsoft 365 connector, warning that new connections may fail and tools may not work properly. Anthropic reported similar issues for Claude, including its Claude for Outlook add-in, and linked them to Microsoft’s incident. Anthropic listed its API and Claude Code as working normally, while claude.ai showed degraded performance without saying whether it was related. Microsoft has said the outage was caused by overloaded software that handles secure connections, not a cyber attack. Users should check each company’s status page if the main apps stop responding.
