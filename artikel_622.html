Anthropic expands text watermarking to older Claude versions beginning November 3

According to the AI giant, it will be the same watermarking technology already in use in Opus 5.5, based on "an imperceptible pattern in word choice" that won't change the accuracy or readability of its output, or contain any identifying information about the user or organization working with Claude.

But it's one thing to worry about the function of artificial intelligence and another to worry about the human element. Lawyers have been caught using AI-generated citations, novelists have been caught relying on AI to write entire books, and scientific researchers have been caught using AI in the peer review process.

For all the problems solved by AI use, and the mundane busywork it so ably processes in seconds rather than hours, it also creates a powerful incentive for humans to cut corners and lie about it, so it will be interesting to see if widespread watermarking helps keep the human element honest.
