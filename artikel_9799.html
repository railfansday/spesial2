I built an AI memory that says “not found” instead of guessing

Tanggal: 2026-11-06

Try it free: dorothy.panaxon.ai. Upload a document and ask it anything.

For the past several months I've been building M.N.E.M.O. (Multidimensional Neural Elastic Memory Organization), a memory layer for AI that doesn't rely on vector search.

Similarity search always returns something, even when the answer isn't in your documents. The model then answers confidently from the wrong context, and you can't tell.

M.N.E.M.O. stores what you give it in a structured tree and looks up answers by exact path instead of by similarity. Two things come out of that:

It doesn't remove every way an LLM can go wrong. What it removes is being handed the wrong context in the first place.

It depends on the model choosing the right path, and I haven't benchmarked that at large scale yet.

A free account keeps your memory between sessions and lets you ask questions of knowledge other people have shared. Upload a document, ask something hard, then ask something that isn't in it, and see what happens.

If it gets something wrong, I'd really like to know. Leave a comment here.
