Remote ID for developers: what's actually in the broadcast, and what the FAA Part 107 test asks about it

Tanggal: 2026-11-12

If you build anything that touches drones (a flight logger, a mapping pipeline, a fleet dashboard, a hobby receiver on an ESP32), you'll run into Remote ID. It's the FAA rule that makes most drones broadcast who and where they are, and it's also one of the topics on the FAA Part 107 Remote Pilot knowledge test.

Here's a developer-friendly breakdown of both: the data, and the exam angle.

Remote ID is 14 CFR Part 89. Since the compliance date (September 16, 2023, with FAA enforcement discretion that ended March 16, 2024), drones that are required to be registered must broadcast identification and location data while they fly, unless they're flown inside an FAA-Recognized Identification Area (FRIA). It's a local broadcast, not a network service: there's no cloud API you can query for every drone in the country.

A broadcast module sends a slightly different set (14 CFR 89.315): the module's serial number, the drone's position, altitude and velocity, a time mark, and the takeoff location instead of the live control station location.

That difference is a classic exam trap: standard RID tells observers where the pilot is; a module tells them where the drone took off.

The FAA accepted the ASTM F3411 standard as a means of compliance, and the open-source ecosystem around it is called OpenDroneID. Messages go out over Bluetooth (legacy advertising and long range) and Wi-Fi (Beacon / NAN), so a normal phone can receive them. If you want to play, the OpenDroneID project publishes receiver code for Android, and there are ESP32 transmitter and receiver projects for test benches. (Transmit only on your own bench or in compliance with FCC rules, and never spoof real IDs.)

The test is 60 multiple-choice questions in 2 hours at a PSI testing center, and you need 70% to pass. Remote ID is a small slice. The big point-losers are usually sectional charts and METAR/TAF weather codes. One recent change worth knowing: since October 26, 2026, some chart questions use images from current sectional charts that aren't in the printed testing supplement, so practice on a current FAA sectional.
