BTCPay Server warns of hot wallet thefts running on outdated software

Tanggal: 2026-11-03

BTCPay Server urged operators to shut down their servers after receiving reports of unauthorized attackers draining funds from hot wallets.

BTCPay Server has identified an attack vector affecting older versions of its payment software after receiving reports of attackers draining funds from users’ hot wallets.

On Monday, the Bitcoin payment platform said its investigation identified an attack vector targeting instances running version 2.4.1 or earlier, which was released July 23, 2026.

The project said it had received no credible reports of hot wallet drains among users running its latest release, version 2.4.7 and urged operators to update their installations.

The findings followed an earlier warning, in which BTCPay urged operators to shut down server instances while it investigated the unauthorized wallet withdrawal reports. It also shared instructions for operators to shut down their servers.

BTCPay has not disclosed the number of affected operators, the value of stolen funds or technical details explaining how attackers accessed the wallets. It asked affected users to submit information and logs to its security team.

Cointelegraph reached out to BTCPay Server for comment but did not receive a response before publication.

The reports come less than three months after BTCPay restricted remote Lightning access following an August attack that exploited a vulnerability to obtain Lightning Network Daemon (LND) credentials and steal funds.

It remains unclear whether the latest attack vector is connected to the August vulnerability.
