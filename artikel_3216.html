Google’s AdMob lets AI agents like Claude Code set up app ads

Tanggal: 2026-11-16

A Gemini assistant for fixing ad problems is coming too, but most of the tools are still in testing.

Google has released AdMob agent skills that let AI coding agents, including Claude Code, Codex and Cursor, add and check ad code in mobile apps. A Gemini-built assistant, Ask AdMob, and an MCP server that lets agents manage AdMob accounts are still in testing, with more agent tools planned for 2027.

Google is adding AI tools to AdMob, its service for showing ads inside mobile apps, the company announced on Monday. The one available now lets developers hand ad setup to AI coding agents, including rival tools such as Claude Code, Codex and Cursor. The rest is still in testing.

The new “agent skills” are ready-made instructions that teach an AI agent how to work with Google’s ad code. Developers can ask it to add banner or full-screen ads, move to Google’s newest ads toolkit, or check an app for setup errors before launch. Google says this replaces clicking through dashboards and copying ad IDs by hand.

Google is also building an MCP server, a link that would let agents read AdMob account data, create ad slots and change settings. It is in early testing and should reach more developers early next year. Developers will have to approve changes before they go live.

The second tool, Ask AdMob, is a chat assistant built with Gemini that sits inside a developer’s AdMob account. Google says it will flag setup problems, suggest ad networks that could earn more, and catch typos in pricing settings. Developers can also set brand safety rules in plain language instead of keeping block lists.

Testing of Ask AdMob starts over the next few months. Google plans features that act on a user’s behalf later in 2027, but says every suggestion will still need approval.

Supporting outside agents fits a wider industry shift. In August, OpenAI and four rivals agreed on one standard for agent skills and MCP servers. IronSource’s founders, who sold their app ad company for $4.4B, are betting AI agents will replace ad buyers altogether.

For Google, keeping app makers on its ad network matters, as Meta is set to overtake it as the world’s biggest ad company this year.
