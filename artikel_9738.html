TRENDnet TEW-657BRM Returns Seven App Matches and No Patch Path

Tanggal: 2026-11-16

The TRENDnet TEW-657BRM is a 150 Mbps wireless ADSL modem router. It is an old device with a small public fingerprint, which makes a count useful for an inventory conversation rather than for a vulnerability claim. On 2026-11-17 between 05:45 and 05:46 Asia/Shanghai, ZoomEye returned 7 matches for app="TRENDnet TEW-657BRM", 0 for title="TEW-657BRM", and 4 for http.body="TEW-657BRM".

The probes used sub_type=all, page 1, and page size 1. The application field is the most specific observation. The title field returned no matches, and the body field returned four pages that mention the model. A zero title count does not mean the devices are absent; a router login page may use a generic title.

CVE-2026-129351 describes an out-of-bounds write in the sprintf function used by /setup.cgi, part of mini_httpd, for firmware 1.00.1. The record says the flaw can be reached remotely without authentication and that a public exploit has been disclosed. TRENDnet's support notice says the model is end-of-life and end-of-support and that the vendor cannot provide additional support.

The seven application matches are a small review set. They are a better operational starting point than the body count because the app label is tied to the model. They still require confirmation: a fingerprint can be a support system, a lab, or a device behind a proxy.

Find the device by model and firmware in the asset inventory. If it is still on a production or branch network, remove it or isolate it behind a managed gateway. Disable remote administration, telnet, and unused port forwarding. Change default management credentials and review DNS and firewall rules.

Capture the current configuration before replacement. Look for unexpected administrator sessions, changed DNS, new port-forward rules, and outbound connections to unknown destinations. If the router has no useful logs, use the upstream firewall and DNS records.

The application query is a narrow observed set. A count this small is not a measure of total risk, but it is enough to ask a precise inventory question: which owner still needs a 15-year-old modem router?

Replacement is the clean remediation because the vendor has ended support. A firewall rule can reduce reachability while a replacement plan is funded, but it does not turn an unsupported device into a patched one.
