Morty — Continue your AI agent from any browser

Tanggal: 2026-11-19

I built a small open-source tool to solve a specific annoyance: being able to keep using the AI agent running on my machine when I’m not sitting in front of it.

Previously I used Tailscale + Moshi. It worked, but the experience was laggy and I had to run my own relay to make it tolerable. Other tools that appeared later were either heavyweight or closed-source — I wasn’t comfortable handing my machine to something I couldn’t inspect.

Morty is intentionally narrow. It lets you continue a Claude Code, Codex, or Pi session from any browser (phone, tablet, another laptop). No account, no app install, no manual config. You paste one prompt into an existing session; the agent fetches a public setup document and does the rest (including installing prerequisites if needed). Then you open the link it gives you (or scan a QR code).

Design choices that mattered to me:

  • Conversation history stays on your machine. The browser only ever reads it live from the local daemon; nothing is stored in the cloud.
  • Session payloads are end-to-end encrypted between the browser and the daemon. The Cloudflare relay only forwards ciphertext.
  • Apache 2.0, free for now (the relay isn’t expensive yet).
  • Explicit, time-limited, revocable sharing links if you ever want someone else to join a session.

Setup prompt (paste into any Claude Code / Codex / Pi session):

Fetch https://morty.build/doc/setup.md and complete the Morty setup for me.
You may install missing prerequisites and pair this machine.

Site: https://morty.build
Repo: https://github.com/portalcrew/morty

It’s still early. Known limitations exist (machine has to stay awake, terminal sessions can fork if you don’t exit them first, etc.). Feedback, issues, and critique are welcome.
