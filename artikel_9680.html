Difflin: a zero-dependency text/JSON diff engine (LCS) that runs entirely in your browser

Tanggal: 2026-11-28

Every time I need to compare two JSON payloads or two config files, I end up pasting internal data into some random diff website. That is a bad trade: convenience in exchange for shipping logs and API responses to a third party.

So I built Difflin: a diff tool with no backend at all. The comparison happens inside the browser tab.

The engine is a classic LCS (longest common subsequence) dynamic-programming diff — the same idea behind diff and early git diff implementations — with a line-level pass first and an optional character-level pass inside changed lines.

The tool is free and MIT-licensed. If it saves you time at work and you want the hosted version to keep existing (custom domain, JSON-schema-aware comparison, saved sessions), you can leave a tip:

Bug reports and PRs are more valuable than tips — especially test cases where the character-level pass produces a confusing highlight.
