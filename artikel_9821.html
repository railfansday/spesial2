Ping ishlayapti, brauzer ulanmayapti: Windows Firewall Domain Profile

Tanggal: 2026-11-21

Posted on Nov 21 • Originally published at t.me

Ping ishlayapti. Brauzer esa «Sizga internet yo‘q» deyapti. 😅

Bir Windows kompyuteri domendan chiqsa, saytlar ochilardi. Domenga qayta qo‘shilsa, brauzer va messenjerlar ulanmay qolardi.

Gap shunda ekan. domen siyosati firewall’ni yoqadi. Shunda kompyuterda avvaldan saqlangan «Outbound connections → Block» sozlamasi kuchga kiradi. Firewall o‘chiq paytda bu qiymat saqlanib turadi, trafik esa o‘taveradi.

🛠 Start → wf.msc → Properties → Domain Profile → Outbound connections → Allow (default) → Apply.

«Allow» saqlanganini tekshirdim. Kompyuterni domenga qayta qo‘shgach, brauzer va messenjerlarni yana sinash kerak.
