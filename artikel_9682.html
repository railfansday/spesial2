PostgreSQL 14, 2021 to 2026

Tanggal: 2026-11-12

PostgreSQL 14 died today, November 12, 2026, at the age of five years and six weeks. Its last words were 14.25.

The release note is short about it: "This is the final release of PostgreSQL 14." (PostgreSQL news, Nov 12, 2026)

Dates are from the PostgreSQL versioning page, read November 12, 2026. The file count is GitHub's code search for the exact string image: postgres:14, read November 11, 2026. It is approximate and includes forks, docs and examples.

It went out fixing things. Today's update release, 14.25 among them, closes a list of security issues; the release note gives each one with the versions it affects. Anything found after today stays open on 14.

Nothing stops. A server on 14 starts tomorrow the same way it started today. That is the trouble with this kind of death: there is no error to notice, only fixes that never arrive.

The heirs were named years ago. 15, 16, 17 and 18 are all supported, and pg_upgrade goes from 14 to 18 in one step.

On Amazon RDS, standard support for 14 runs until February 28, 2027, then paid Extended Support (AWS release calendar).
