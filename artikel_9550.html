A yes/no post-quantum migration checklist, checked against the primary sources

Tanggal: 2026-11-17

Most post-quantum migration advice I found was either a vendor pitch or a summary of a summary. So I built a checklist where every item is a yes/no question with a test you can run, and every claim was checked against the standard itself.

Repo: https://github.com/sunilgentyala/pqc-migration-checklist (22 items, MIT)

I read the NSA advisory directly. The PDF at the NSA's URL is PP-22-1338, September 2022, Version 1.0. It names CRYSTALS-Kyber and CRYSTALS-Dilithium with the specification listed as "TBD", so it predates FIPS 203 and 204. Many posts quote dates from it as if they were current. The repo only states what that document says (AES-256, SHA-384 or SHA-512, LMS or XMSS for firmware signing) and says plainly that the current CNSA 2.0 FAQ was not read.

Each README has a "What was not verified" section. For this one it includes the current CNSA 2.0 FAQ, one row of an IR 8547 table that needs a visual check, the ssh -vv negotiated line, and the IANA registry entry for the X25519MLKEM768 codepoint. If you can confirm or correct any of these, there is an issue form.
