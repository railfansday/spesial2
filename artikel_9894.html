1. Have one AI agent document the code fully by explaining how it works in plain english2. Copy that new documentation to an entirely segregated second agent3. Instruct the new agent to write brand new code according to the documentation

It's unlikely this will be done for all OSS projects since the result usually has bugs and inconsistencies. But spend a week or two doing passes over it for improvement and you get a functional reimplementation. (What license that can use will depend on how the law around AI code shakes out in the future)
