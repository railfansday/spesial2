Sony Fighting GTA 6 PS5 Piracy with New Firmware Demands

Tanggal: 2026-11-03

Today's new PS5 firmware reportedly required

PlayStation appears to be taking absolutely no risks, as it closes in on the launch of GTA 6 for its platform while fending off PS5 jailbreak, piracy, and hacking attempts.

From the start of last month, hackers began cracking the PS5 firmware via AI tools on firmware v7.00 through v13.60. In response, Sony has issued multiple PS5 firmware updates to cut down on potential emulators for the current-gen box going forward.

In the past, select titles have required Sony systems to be running the latest firmware in order for those games to boot — Marvel's Wolverine is one example. Now, as it attempts to thwart any potential scenario where GTA 6 is hacked or pirated via a PS5, Sony is reportedly requiring the very latest firmware — today's patch, in fact — in order to run the new Rockstar open worlder.

According to PlayStation Game Size, which scrubs the PS Store backend for details, you'll need a PS5 console running firmware 14.22.00.00 in order to play GTA 6. This is entirely their reporting based on their own findings.

At the start of October, it was claimed you'd need firmware version 14.10.00.00 — it's now reportedly gone up today to 14.22.00.00, with the PS5 patch live and available to download now.

This isn't actually the first time Sony has had to shore up its console security in the lead-up to a big release. During the PS3 generation, Gran Turismo 5 was actually delayed by a few days due to a security issue relating to the console's XMB operating system.

This time around, it looks like Sony isn't taking any risks whatsoever.
