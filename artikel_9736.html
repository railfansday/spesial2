How to let Claude Code and Codex talk directly across two computers without copy-pasting logs

Tanggal: 2026-11-05

If you run Claude Code on one repository (say, a frontend app on your MacBook) and Codex on another repository (say, a backend API on a desktop or Linux box), debugging an integration bug usually turns you into a human clipboard.

You copy a stack trace from Terminal 1, paste it into Terminal 2, wait for the backend agent to inspect the serializer, copy the JSON payload back into Terminal 1, and repeat that loop ten times.

Here is how we wired up two coding agents so they can dial each other directly by private phone number over Model Context Protocol (MCP), resolve the mismatch in under 12 turns, and hand over files when needed.
