A Lightweight TypeScript Router for Building Modern Backend Applications

Tanggal: 2026-11-18

I've been working on Xanout, a lightweight, TypeScript-first server router designed to make backend development simpler and more flexible.

The idea behind Xanout is straightforward: provide developers with a clean routing system built around web standards without introducing unnecessary complexity.

Xanout is a server-side routing library for building HTTP applications and backend services.

It provides a simple foundation for handling HTTP requests, defining routes, and organizing server-side application logic.
