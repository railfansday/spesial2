I bought one of these portable cd players, it can run through bluetooth or an aux cable. Most modern cars you can run find some way to run it.
Or you can you can use headphones/earphones, unless you want to be able to share the music with a passenger. I've never owned a car with a built-in CD player or CarPlay. For several years around 2000, I used a Walkman-type CD player sitting on the passenger seat, with headphones. Then I got a new Mac that came with an iPod Mini as a promotion. I put the iPod in my shirt pocket, and no longer needed to carry CD's in the car. Around 2015 I got my first iPhone, and used it with the same headphones for a few years. Then I got hearing aids that connect to my iPhone via Bluetooth, and have been using that setup for several years. Greatest thing since sliced bread!

But all along I've had a Mac that I can use for ripping my CDs. I've been doing it for about 20 years now, and still have plenty of CDs left to rip, accumulated over more than four decades. I'm currently working on ripping and tagging two complete sets of Bach's organ music, 17 CDs each.
