Hackers Hate This: Building a Security Engineer Inside Claude Code for Node.js Developers

Tanggal: 2026-11-07

Tags: claudecode, security, nodejs, opensource, devsecops

Backend security is one of the most important aspects of modern application development.

Whether you're building a MERN application, an Express API, a NestJS backend or a Next.js application, vulnerabilities can exist across authentication, authorization, database queries, API endpoints and infrastructure configurations.

I wanted to create a reusable security workflow that developers could run directly inside Claude Code.

It is an open-source Claude Code skill designed to perform structured security audits, identify vulnerabilities, generate security tests and help developers harden their applications.

It follows established security guidance, including OWASP Top 10, API Security Top 10, ASVS and CWE.

Discovery → Audit → Report → Approval → Remediation → Verification.

The goal is to provide actionable findings rather than vague security warnings.

The project is released under the MIT License.

I'm looking forward to contributions, independent testing, bug reports and suggestions from the developer and security communities.

GitHub: https://github.com/dev-shamsali/hackers-hate-this
