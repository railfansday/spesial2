My attempt at SEO for rayr.uk

Tanggal: 2026-11-26

I own rayr.uk and I want it to show up when people search "rayr uk" or "ray r uk". Right now it doesn't really. The site is one page with a neon animation and an email button, which looks fine but gives Google almost nothing to read. So I'm trying a few things. First, the boring HTML stuff. I added a proper title, a description, a canonical link and some Open Graph tags so links look right when you share them. I also added a bit of actual visible text, because a canvas animation is just a blank space to a search engine. Second, I added structured data that says rayr.uk, "Ray R UK" and "RayR" are all the same person, and listed my profiles in it. I also made a robots.txt and a sitemap and sent the sitemap to Google Search Console. Third, I made accounts on the places I'd probably use anyway, like Instagram, TikTok, YouTube, SoundCloud and Linktree, and tried to use the same name and bio on all of them, each one linking back to the site. From what I understand, Google trusts a name more when a bunch of separate places agree on it. This post is also part of that. A dev.to or Medium profile with something on it should count for more than an empty one. I don't know if any of it will work. "Ray R" is a pretty common name, so it might not. This is just what I'm trying and why, I'm writing this post in a bid to increase my SEO footprint. My site is rayr.uk: (https://rayr.uk).
