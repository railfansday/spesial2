Name Localized Screenshots Once: Files That Work with fastlane deliver and supply

Tanggal: 2026-11-14

Give every screenshot a predictable destination and sequence number, and your next caption revision becomes a repeatable file operation. The same organization also makes manual uploads easier: you can find one language, one device, and the intended first image without opening every PNG.

This worked example turns localized exports into fastlane's two different directory structures. It focuses on the boundary between your image generator and your uploader.

Disclosure: I build ScreenParcel, a browser tool that combines app screenshots with your own translated caption text and exports multi-locale screenshot packs as one ZIP. It does not auto-translate.

Suppose a release has two screenshots per language, with iPhone, iPad, and Android phone artwork. Keep iOS and Android captures in separate exports when their interfaces differ.

Deliver detects device types from image resolution. The device suffix makes flattened filenames unique and readable; it does not assign the device slot. Its loader reads image files directly within each language folder, so an extra ordinary iphone-69/ subfolder is unsuitable here. See the deliver documentation and screenshot loader.

Supply also recognizes sevenInchScreenshots/, tenInchScreenshots/, tvScreenshots/, and wearScreenshots/. Add those only for appropriate assets. ScreenParcel currently exports a Google Play phone size; the script below maps that size alone to phoneScreenshots/. These directory names come from supply's image documentation.

Keep your repository's normal metadata alongside these images. A screenshot staging directory does not need to contain your titles, descriptions, or changelogs.

Treat this tree as generated output. Keep the original exports outside it, and rebuild the staging directory when artwork changes. Otherwise, removing screenshot three from an export can leave yesterday's third PNG in the upload folder. Copying a new pair over an old set cannot express that deletion.

For this example, position one demonstrates the app's main action and position two shows its result. Use that same sequence for every language and device. A reviewer can compare the two positions across folders without guessing which image belongs where.

A locale is an uploader input. Do not derive it by blindly appending a country code.

These target identifiers are supported by fastlane's deliver language list and Google's listing-language reference.

Mexico and Latin America are different audience scopes. Reuse an es-MX export for es-419 only after approving its wording for the broader listing. A directory rename does not adapt the copy.

Norwegian deserves special attention: ScreenParcel's current code normalizes no input to nb, while deliver's accepted directory is no. Google lists no-NO, rather than nb-NO, for its Norwegian store listing. Preserve your own app's internal locale identifiers; apply this mapping at the export boundary.

Use 01-, 02-, through 10- consistently. Plain alphabetical sorting can put 10- before 2-; padding removes that ambiguity across scripts and file pickers.

Supply uses alphanumeric filename order. Deliver's upload code applies natural filename sorting within screenshot sets. Fixed-width prefixes work with both. Deliver's sorting implementation shows that ordering step.

Keep the number first, followed by a stable label and optional device suffix. When two sizes share one iOS locale folder, 01-device--iphone-69.png and 01-device--ipad-13.png remain distinct. Their dimensions put them into separate device sets.

The current ScreenParcel editor uses one headline and subtitle per locale across uploaded screenshots. If you export separate passes for different captions, assign their final sequence numbers before combining them: every pass starts its filenames at 01.

Review existing remote assets when choosing replacement behavior. Supply replaces the screenshot set it uploads. Deliver offers overwrite_screenshots to clear existing screenshots before upload; use it only when the staged files cover the intended replacement scope. Both behaviors are documented in the linked action references.

For manual uploads, use the same staged tree. On Apple, filter a locale folder by its device suffix, then select the numbered images. On Play, open the matching phoneScreenshots/ folder. Sort by name and confirm the console's displayed sequence; a file picker need not preserve selection order.
