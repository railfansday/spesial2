How Timefolk Is Turning Individual Expertise Into Small Group Sessions

Some skills are easier to practise when more than one person is involved. A presentation can benefit from an audience. Language practice becomes more dynamic with several voices in the room. Interview preparation can expose people to different questions and responses.

Timefolk is extending its skills marketplace around that idea. Through Timefolk, Experts can run small group Events built around a specific skill, with several Clients joining the same practical, in-person session.

The format keeps the same basic structure that sits behind the wider marketplace. The skill, city, session fee and number of available places are clear before someone joins.

In the app, Clients can find an Event through Explore and see the date, skill, fixed session fee, city and remaining spots on the Event card. They can then join and pay through the app. The purpose is established before the group comes together rather than being decided once everyone arrives.

An Expert could run a session around interview practice, Business English, presentation skills, SI tools for work or another practical skill they already use. Several Clients can take part in the same session, creating a different format from an individual session while keeping the activity clearly defined.

For Experts, the group model creates another way to share what they know. Instead of running the same type of session individually with several Clients, an Expert can bring a small group together around one skill. The Expert sets the session fee and the number of available places, while Timefolk provides the marketplace and platform infrastructure around the session.

For Clients, the value is not only the possibility of a lower session fee per person. The group itself can become part of the experience. Someone practising a presentation can receive reactions from more than one participant, while a language session can include different speaking partners. A career focused session can give Clients the opportunity to hear how others approach the same challenge.

The Event still remains tied to one defined skill rather than becoming a general gathering. That distinction is important to Timefolk’s wider positioning as a marketplace for practical, in-person sessions with local Experts.

The platform also keeps the same emphasis on structure. Only ID verified members can join an Event, and every Expert and every Client passes a government ID and liveness check before a session. The exact place is provided before the Event, and the venue must be public. Timefolk’s current product material excludes homes, bars and private rooms from the Event format. Timefolk-media-deck

The session begins through an Event code or QR, creating a clear point at which attendance is recorded. Timefolk also states that only people who attended can leave a review. Timefolk-media-deck

Payments are handled through the app, with Clients able to use methods including Apple Pay, Google Pay or a saved card. Timefolk’s broader payment infrastructure uses Stripe. Timefolk-media-deck

The company has also built specific features around the group format. Its current media deck describes a shared Event page, a QR image that Experts can use when promoting the session, a list showing who attended and tools for managing the Event inside the platform. Clients can receive a full refund if an Event is cancelled or if they leave at least 24 hours before it starts. If the time or place changes, the platform provides a window for Clients to leave without charge. Timefolk-media-deck

Those details matter because group sessions create different operational questions from individual sessions. The platform needs to show who has joined, how many places remain, what happens if the venue changes and how attendance is confirmed.

Timefolk is trying to answer those questions inside the product rather than leaving them to informal coordination. That makes Events more than simply an additional format. They show how a skills marketplace can expand without losing the structure that defines the original model.

One Expert can offer a practical skill to several Clients while the purpose, session fee, location and participation rules remain visible from the beginning.

For Timefolk, that creates another way for expertise to move through a city. A practical skill no longer has to be shared with one Client at a time. It can become a small group session built around the same clear outcome.
