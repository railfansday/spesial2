Form submitted, invoice sent: building a Form-to-Invoice flow in n8n

Tanggal: 2026-11-18

If you sell services, the gap between "the client filled in the order form" and "the invoice is in their inbox" is where getting paid quietly stalls. You copy line items into a spreadsheet, work out the totals, save a PDF, attach it to an email, and file a copy somewhere you will never find again. It is five minutes of admin per order, and it is the five minutes that gets skipped.

This post walks through a small n8n workflow that closes that gap: nine nodes, no manual steps between form submission and sent invoice.

currency, tax_rate, and due_days are all optional — the defaults are USD, no tax, and 14 days. A single-line order also works with plain description, quantity, and unit_price fields instead of an array.

1. New Order Form (Webhook). The entry point. Any form tool that can POST JSON works here — a website form, a Typeform webhook, or a simple HTML form pointed at the production URL.

2. Build Invoice (Code). The brains of the workflow. It does four things in order: it validates client_email first and throws an error if it is missing or invalid, so a bad address fails loudly instead of silently dropping an invoice; it normalizes the order lines; it computes subtotal, tax, and total; and it stamps an issue date, a due date (issue date plus due_days), and an invoice number in the format INV-YYYYMMDD-xxxxx.

3. Save Invoice to Sheet (Google Sheets). Every invoice lands in one row, with these headers: Invoice ID, Client name, Client email, Items, Subtotal, Tax, Total, Currency, Issue date, Due date, Status. This is the audit trail — and the Status column is where you later mark invoices paid, or spot the overdue ones.

4. Create Invoice File (Code). This turns the invoice into an HTML file (Invoice-INV-....html) carried in a binary field both downstream nodes read. It opens in any browser and prints cleanly to PDF, so the client never needs special software to read it.

5. Send Invoice Email (Gmail). Sends the file as an attachment. Before activating, replace the [Your Name] / [Your Business Name] placeholders in this node and paste in your payment link or bank details.

6. Archive Copy to Drive (Google Drive). Saves the same file into a folder you pick. One copy goes to the client, one copy stays with you — no more hunting through sent mail when a client asks for a copy in six months.
