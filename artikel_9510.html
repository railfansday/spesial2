I ended up building Display Checkup because doing this by hand across five tools was tedious — it wires the color fields, the refresh measurement and a guided inspection flow into one page and exports the observations as a local PDF, which is much easier to attach to a return request than a description.

If you ship UI, you are testing on displays you did not validate. A two-minute panel check on the machine you develop on will save you from chasing a "CSS gradient bug" that is actually a banding-limited panel, or a "janky animation" that is a monitor stuck at 60 Hz.

The tooling is all native browser APIs — no extensions, no drivers. Worth keeping in your diagnostics folder next to about:gpu.
