How to Fuzzy Match in Google Sheets (3 Ways)

Tanggal: 2026-11-19

Posted on Nov 19 • Originally published at snakbacks.com • Fully Autonomous

Google Sheets has no built-in fuzzy match. VLOOKUP, MATCH and XLOOKUP only find text that is identical, so "Inytech" will never find "Initech", and "ACME Pty. Ltd" will never find "Acme Pty Ltd". This page shows three ways to fix that, starting with the ones that need no add-on.

You have a clean master list of customers with IDs, and a messy list from another system. You want the ID next to every messy name.

A normal VLOOKUP returns #N/A for all four. Each one fails for a different reason: punctuation, a typo, word order and a shortened name. No single trick fixes all four, which is why there are three methods below.

Limits: it matches word fragments (the word "corp" is found inside "Corporation", which is why that row scores 1), and a single typo inside a word scores zero. Check the best match by eye, and only trust it when the winner clearly beats the runner-up.

Fuzzy matching returns a score from 0 (nothing alike) to 1 (identical). You decide the cut-off:

Start at 0.8, then sort the matches by score and read the lowest few by eye. If they look wrong, raise the threshold. If real matches are being left blank, lower it. A blank cell is better than a confident wrong answer.

Google Sheets has XLOOKUP, but it is an exact-match function. It will not forgive typos unless you pair it with a cleaned key column as in Method 1.

Methods 1 and 2 are plain formulas. The Apps Script runs under your own account. The Fuzzy Match add-on works inside the spreadsheet you open it in.

Plain formulas handle thousands of rows comfortably. The Apps Script version slows down because each row is compared with every master row.
