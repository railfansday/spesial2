Polyend releases the Tracker firmware source code

Tanggal: 2026-11-03

Today we’re publishing the firmware source code for the original Tracker, Tracker+ and Tracker Mini on GitHub. We’re also releasing Tracker Community Edition 1.0 with tons of new features and improvements. You can install it on any of the three instruments, modify the firmware yourself and share your own version. We’ve built in a recovery system to keep a faulty firmware build from bricking your Tracker. Explore the Tracker Community Edition repository on GitHub

“Here at Polyend, creativity is what we value most. We’ve seen it firsthand in the unofficial Tracker mods you’ve built, and we’re sharing the firmware source code to support that work. Maybe you want to build an entirely new instrument on the Tracker hardware. Or maybe there’s just one thing you wish your Tracker did differently. Either way, you can now try it on the unit you already own. I bet some of you already have ideas for the original Tracker that never crossed our minds.” Piotr Raczyński, CEO of Polyend

All three models also get wavetable envelopes and LFOs, faster project loading and saving, and tighter MIDI clock timing. You can design custom Tracker themes and fonts in your browser. See all the new features, improvements and fixes in the full changelog

Huge thanks to @Piotr and the whole Team at Polyend for allowing me to do this .
