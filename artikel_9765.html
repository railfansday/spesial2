A browser stopwatch that stays right when the tab sleeps

Tanggal: 2026-11-09

A stopwatch looks like the easiest tool to build: add 10 ms every 10 ms and print the total. That version is wrong within minutes in a background tab. Here is how the stopwatch on my site keeps time instead.

Browsers slow down timers in hidden tabs, and a phone with the screen off may not run them at all. Any stopwatch that adds up ticks loses exactly that time.

So the state is three numbers: whether it is running, the moment it was started, and the time banked from earlier runs.

Pause moves the current run into acc and clears startedAt. Start sets startedAt to now. The display timer only decides how often the number is redrawn; it never changes the number. If the tab sleeps for a minute, the next redraw is simply a minute further on.

performance.now() is the better clock for measuring, because it doesn't jump if someone changes the computer's clock. But it starts again from zero on every page load, and I wanted the stopwatch to survive a reload. Date.now() can be saved and compared after a reload, so I chose it and accepted that changing the system clock mid-run will show up in the total.

The state is saved to the browser's storage after every start, pause and lap. On load it goes through a strict check: running must be a boolean, acc and every lap a finite number of zero or more, and a running stopwatch must have a start time. Anything else gives a fresh stopwatch rather than a strange total. In testing I fed it {"running":true,"acc":5}, a running state with no start time, and it came back as a clean zero.

A lap stores only the total time at that moment. The length of each lap is worked out when the table is drawn:

That keeps the saved data small. With laps at 1:02.34, 2:05.10 and 3:10.87 in total, the splits are 1:02.34, 1:02.76 and 1:05.77, and once there are more than two laps the table marks the fastest and the slowest.

The display truncates to hundredths rather than rounding, so 65,329 ms shows as 1:05.32. Rounding would sometimes show a time the stopwatch hadn't reached yet.
