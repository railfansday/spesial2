How I Built an Open Online Typing Game Platform with Real-Time 1v1 Multiplayer in React

Over the past few months, I set out to build TypingGame.in (https://typinggame.in) — an interactive, completely free online typing academy and arcade game portal.

While platforms like Monkeytype and TypeRacer dominate the market, I wanted to build something that blended educational touch-typing curriculums, real-time 1v1 PvP racing, and arcade gameplay (car racing, bubble popping, and zombie defense) into a single cohesive web application.

Here is a breakdown of how the architecture works, how WPM is calculated accurately, and how real-time 1v1 sync is handled.

A common issue in novice typing tests is treating each space-separated word as a single unit. In professional and government certification standards (such as SSC CGL and RRB), typing speed is universally standardized to 5 keystrokes = 1 standard word.

Here is the exact formula implemented in the speed test engine:

Gross WPM = (Total Characters Typed / 5) / Time Elapsed in Minutes

Net WPM = max(0, (Correct Characters / 5) / Time Elapsed in Minutes)

Accuracy % = (Correct Characters / Total Characters Typed) * 100

By evaluating velocity against Date.now() timestamps rather than relying on setInterval tick counts, the speedometer remains immune to browser background throttling or tab switches.

One of the trickiest challenges when building an interactive typing game online (https://typinggame.in/) is handling smartphone virtual keyboards (like Android Gboard or iOS Safari).

On desktop keyboards, pressing any key fires a standard KeyboardEvent with e.key.length === 1. On mobile devices, however, virtual keyboards use Input Method Editors (IME) with predictive composition, which often emit e.key = 'Unidentified' and keyCode: 229.
