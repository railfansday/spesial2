The Model Was Up. Your AI Agent Was Still Broken: Lessons From the Microsoft 365 Outage

Tanggal: 2026-11-26

Posted on Nov 26 • Originally published at aviasole.com

On the afternoon of November 12, 2026, an AI assistant that reads a sales team's Outlook inbox starts giving the same answer to every question: "I couldn't find any emails about that." No error page. Nobody gets paged. The model provider's dashboard is green.

The assistant asked for the emails, the request failed, and the model did what models do with a failed tool call: it wrote a fluent, reasonable-sounding sentence about it.

That was the start of a Microsoft 365 outage that lasted about a day. The models behind ChatGPT and Claude kept working the whole time. The AI features that depended on Microsoft did not.

If you were relying on other people's status pages to understand your own product's health, you were working from a delayed, moving picture.

The model absorbs the error. A failed tool call goes back into the context, and the model writes "no results found". The user sees an answer. Your HTTP monitoring sees 200 OK.
